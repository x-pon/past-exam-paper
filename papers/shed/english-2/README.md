# 自考英语二（00015）

本目录对应高等教育自学考试**英语（二）**科目的真题整理，课程编码一般为 **00015**。仓库内经讨论采用英文目录缩写 **SHED**（自考）挂载于 `papers/shed/`。

若某套试卷来源文件名中的编码与 00015 不一致（例如 **00013**），则文件名与索引中的中文名应写作 **自考英语二（00013）**，以与实际编码一致。

## 存放约定

- 真题 PDF/扫描件等**直接放在本目录**，不再按日期单独建子文件夹。
- 建议文件命名：`年月（如需可含日）-自考英语二（课程编码）.pdf`（日期段与主题名之间用 **`-`**；课程编码一般为 **（00015）**，全角括号与数字五位数。索引里 `subject` 仍填 `english-2`。）
- 若同一考次需保留多份文件且主文件名相同，则在主名后加序号：`-01`、`-02`（首份可不加后缀）。

若你仅维护索引与来源链接，也可以不放置文件，只在 `index/papers.csv` 中记录信息。
