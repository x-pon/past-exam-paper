# 公共英语：PETS

## 目录约定（按等级平铺）

真题文件放在对应等级目录下，**不再**使用 `YYYY-MM/` 子目录，例如：

```
papers/pets/
  PETS-1/
  PETS-2/
  PETS-3/
    2010年9月-公共英语三级(pets-3).pdf
    ...
  PETS-4/
  PETS-5/
```

## 文件命名

- 格式：`年月（必要时含日）-中文名(英文简称).扩展名`（日期段与主题名之间用 **`-`** 分隔）  
  示例：`2010年9月-公共英语三级(pets-3).pdf`（月份写为 **1–12**，一般不加前导零）
- 英文简称与等级对应，如 PETS-3 写作 `(pets-3)`（全小写、带连字符）
- **重复文件**：同主名多份时依序使用 `-01`、`-02`…（首份无后缀），例如  
  `2010年9月-公共英语三级(pets-3).pdf`  
  `2010年9月-公共英语三级(pets-3)-01.pdf`

## 索引

- 等级写法统一为：`PETS-1` / `PETS-2` / `PETS-3` / `PETS-4` / `PETS-5`
- 具体真题若涉及版权，请优先只收录来源链接到 `index/papers.csv`
