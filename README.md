# past-exam-paper

历年考试真题资料库，希望让备考时找真题这件事简单一些。

## 为什么创建这个项目？

我参加自考时，每次考试前找历年真题都很费劲。有时候为了找到一套真题，就要花掉大半天，还不一定能找到。于是我把收集到的真题整理在这里，希望能帮备考的同学省下找真题的时间，把精力更多的用在学习上。

## 试卷目录

- [自考英语二（00015）](papers/shed/english-2/README.md)
- [公共英语 PETS](papers/pets/README.md)

试卷文件保存在 `papers/` 下，具体分类和命名方式见各考试目录中的 README。
